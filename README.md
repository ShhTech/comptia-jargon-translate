# comptia-jargon-translate
COMPTIA A+ Jargon Translator &amp; Quiz Tool
A command line utility built for active recall, term lookup and quizes
Features
**Term Lookup** Instant searching for CompTIA terms and analogies
*Interactive Quiz Mode:** Random definition questions with instant answer verification

How to run
Ensure python 3 is installed on your system
Clone or download repository
Open Command prompt/ Terminal in the project folder and run ***cmd py study.py
